## ما يعمل في النسخة الحالية

- لوحة قيادة أفقية حديثة مع العربية RTL والإنجليزية.
- الوضعان النهاري والليلي.
- عداد السرعة وRPM والوقود والمدى وحرارة المحرك والبطارية.
- بطاقة ضغط الإطارات وحالة المركبة.
- وضع رحلات برية يتضمن البوصلة والموقع والارتفاع ونقاط الرحلة.
- اكتشاف GPS وAndroid Automotive وحزمة GWM المعلنة وتطبيقات الخرائط والوسائط.
- قراءة آمنة ومباشرة لبيانات المركبة المتاحة عبر Android Automotive Car API.
- مسار توافق إضافي لخدمات GWM/BeanTechs الموجودة في بعض شاشات H9 موديل 2025.
- تقرير تشخيص قابل للتمرير والنسخ والمشاركة لمعرفة مصدر البيانات والحزم والصلاحيات.
- سرعة وموقع وارتفاع واتجاه حقيقي عبر GPS بعد منح الصلاحية.
- تشغيل تطبيق الخرائط أو الوسائط الأصلي عبر Android Intents.
- وضع Demo محلي واضح ومستقل.
- تخزين Room للرحلات والصيانة، وDataStore للإعدادات.
- صفحة تشخيص لا تعرض VIN أو الإحداثيات أو المعرفات الشخصية في تقريرها.
- قراءة موسعة لـ36 إشارة GWM على شاشة SA8155، تشمل حرارة وضغط الإطارات والرحلات والاستهلاك والقير والدفع والعجلات والعزم.
- فحص تلقائي لتحديثات GitHub مع أيقونة تنبيه وتنزيل متحقق من البصمة والتوقيع قبل التثبيت.

## حدود هذه النسخة

تعتمد القيم الحقيقية على واجهات القراءة التي تكشفها شاشة السيارة للتطبيقات الخارجية. إذا حجبت GWM بعض الإشارات، سيعرض التطبيق المصدر والصلاحيات المفقودة بدل إظهار رقم غير موثوق. لا تحتوي النسخة على أي كتابة إلى السيارة أو CAN Bus أو قراءة VIN.

## البناء

المتطلبات:

- JDK 17.
- Android SDK Platform 36.
- Android SDK Build Tools 36 أو أحدث.

```bash
./gradlew assembleDebug
```

النتيجة:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## الاختبار

```bash
./gradlew testDebugUnitTest lintDebug
```

## التثبيت

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -W -n com.h9smartdrive.app.debug/com.h9smartdrive.app.MainActivity
```

الإصدار الموزع على GitHub يُبنى بنوع `release` ويستخدم توقيعًا ثابتًا؛ لا تستخدم APK بنوع `debug` كتحديث فوقه.

راجع [دليل اختبار السيارة](docs/VEHICLE_TESTING_AR.md) قبل الاستخدام على الشاشة الأصلية.
ولموديل H9 2025 راجع [دليل التوافق والتشخيص](docs/H9_2025_COMPATIBILITY_AR.md).
