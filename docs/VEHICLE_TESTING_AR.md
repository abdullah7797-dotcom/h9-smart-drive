# اختبار النسخة على شاشة Haval H9

## قبل التثبيت

1. أوقف السيارة في مكان آمن وشغّل وضع P وفرامل التوقف.
2. تأكد من إمكانية الرجوع إلى النظام الأصلي.
3. لا تجعل التطبيق واجهة رئيسية افتراضية في أول اختبار.
4. احتفظ بنسخة من APK السابق إن وجدت.

## التثبيت والتشغيل

```bash
adb install -r H9-Smart-Drive-MVP-debug.apk
adb shell am start -W -n com.h9smartdrive.app.debug/com.h9smartdrive.app.MainActivity
```

## قائمة الفحص

- تأكد أن أشرطة النظام والكاميرا والتنبيهات الأصلية تستطيع الظهور.
- افحص الدقة والقصّ واتجاه RTL في الوضعين النهاري والليلي.
- امنح الموقع وتحقق من تحوّل مصدر السرعة إلى GPS.
- أوقف GPS وتأكد أن القراءة تصبح `—` ولا تبقى قيمة قديمة.
- افتح الخرائط والراديو والوسائط وتحقق من العودة إلى التطبيق.
- أطفئ الشاشة وشغّلها وتحقق من استعادة آخر الإعدادات.
- راقب الذاكرة والمعالج وLogcat مدة 30 دقيقة.
- لا تختبر التخصيص أو الإدخال المعقد أثناء حركة السيارة.

## سجلات آمنة

```bash
adb logcat -c
adb logcat --pid=$(adb shell pidof -s com.h9smartdrive.app.debug)
```

راجع السجل قبل مشاركته واحذف أي VIN أو إحداثيات أو بيانات شخصية قد تضيفها تطبيقات النظام الأخرى.

## معايير إيقاف الاختبار

أوقف التطبيق فورًا إذا حجب كاميرا الرجوع أو تحذيرًا أصليًا، أو تسبب في بطء الشاشة، أو استمر بعرض قراءة قديمة وكأنها حية.
