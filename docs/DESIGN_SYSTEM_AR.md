# نظام التصميم

## الألوان

- الخلفية الليلية `#0D1117`.
- بطاقات الليل `#161D27`.
- اللون الأساسي `#60B5E8`.
- الطبيعي `#34D399`.
- التحذير `#F59E0B`.
- الحرج `#EF4444`.
- الخلفية النهارية `#F1F5F9`.
- بطاقات النهار `#FFFFFF`.

## المبادئ

- بطاقات Modular بزوايا 24dp.
- عناصر لمس لا تقل عن 48dp في المسارات الأساسية.
- أرقام القيادة كبيرة وتباين مرتفع.
- اللون ليس الوسيلة الوحيدة لشرح الحالة؛ يوجد نص ومصدر للقراءة.
- الحركات الدائمة غير مستخدمة. تحديث العدادات محدود بمعدل مصدر البيانات.
- التخصيص المتقدم مخصص للتوقف.
