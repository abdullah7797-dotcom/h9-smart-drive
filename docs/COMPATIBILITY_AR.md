# تقرير التوافق — MVP 0.1.0

| الوظيفة | الحالة | المصدر/الملاحظة |
|---|---|---|
| الواجهة العربية والإنجليزية | مدعومة | Compose وRTL |
| الوضع الليلي والنهاري | مدعوم | إعداد محفوظ محليًا |
| السرعة | مدعومة مبدئيًا | GPS؛ تحتاج اختبارًا على الشاشة |
| الموقع والارتفاع والبوصلة | مدعومة مبدئيًا | GPS؛ الدقة تعتمد على الجهاز |
| تشغيل الخرائط والوسائط | مدعوم مبدئيًا | Intents؛ يعتمد على التطبيقات المثبتة |
| Android Automotive | اكتشاف فقط | لا تُطلب صلاحيات Car الخاصة دون توفرها |
| GWM Adapter | اكتشاف فقط | الربط الفعلي يحتاج عقد Binder واختبار السيارة |
| RPM والوقود وحرارة المحرك | Demo فقط حاليًا | تظهر `—` في الوضع الحقيقي |
| ضغط الإطارات | Demo فقط حاليًا | تظهر `—` في الوضع الحقيقي |
| OBD-II | غير مهيأ | خيار مستقبلي غير إلزامي |
| الميلان الطولي والجانبي | غير متاح | لا يُعرض رقم دون مستشعر معاير |
| سجل الرحلات والصيانة | قاعدة البيانات جاهزة | واجهات الإدخال التفصيلية ضمن المرحلة التالية |
| تقرير تشخيص JSON/TXT | نموذج البيانات جاهز | التصدير من الواجهة ضمن المرحلة التالية |

لم يتم الادعاء بنجاح أي تكامل مع خدمات GWM. المرجع الذي تمت دراسته يستهدف Android 9 ودقة `1920×720`، لكن اختلاف نسخ السوق السعودي والخليجي يستلزم فحص كل شاشة فعليًا.
